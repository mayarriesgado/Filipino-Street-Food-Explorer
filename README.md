# Filipino Street Food Explorer

This static website is designed to showcase Filipino street food discovery with a modern editorial style, durable search, region/category filters, and interactive food detail modals.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any local static server:

```bash
cd Filipino-Street-Food-Explorer
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — page structure
- `styles.css` — all styling and responsive layout
- `script.js` — data, filtering, rendering, and modal behavior

## Features included

- Sticky navigation with responsive mobile menu
- Hero section with brand messaging and call-to-action buttons
- Quick exploration category cards
- Search for street foods by name or keyword
- Filter panel for category, region, price, flavor, and texture
- Responsive food card grid
- Detail modal with ingredients, preparation notes, flavor profile, and cultural context
- 20 Filipino street food entries covering the requested list
